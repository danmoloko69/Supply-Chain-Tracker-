# Supply-Chain-Tracker

This is a decentralized application that allows manufacturers, distributors, retailers and customers to track products as they move through the supply chain using blockchain technologies. By recording status update and ownership transfer, that provide transparent product traceability. 

**Why blockchain?**

The traditional supplychain has several issues like; difficult to trace product, recoreds can be altered and mutliple organization maintain seperate databases.

**What this application does:**

1. Register products by manufacturer.
2. Track ownership changes from different supplychain parties.
3. Display complete product history.
4. Records shipment progress.
